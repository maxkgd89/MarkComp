# Markdown Review Studio — Sample Document

This is a realistic sample document used to exercise the structure tree, folding and (later) the diff engine. It intentionally mixes most common Markdown elements.

## 1. Introduction

### 1.1 Background

Large Markdown documents generated by AI agents are awkward to review. You usually end up with two text files and a lot of scrolling. This project exists to make that workflow pleasant.

> **Goal:** review and revise a document while keeping the original untouched.

### 1.2 Objectives

- Compare an original document with a revision side by side.
- Navigate quickly using the document structure.
- Identify changes down to individual words.

## 2. Backend

### 2.1 Database

The backend uses a small embedded database. No external service is required.

```sql
CREATE TABLE documents (
  id      INTEGER PRIMARY KEY,
  title   TEXT NOT NULL,
  content TEXT NOT NULL
);
```

### 2.2 API

| Endpoint | Method | Description |
| --- | --- | --- |
| `/documents` | GET | List documents |
| `/documents/:id` | GET | Fetch one document |
| `/documents` | POST | Create a document |

## 6. Closing Notes

Long paragraphs like this one are included to make sure the editor handles text that wraps across multiple lines without breaking the folding logic. The comparison engine should treat this paragraph as a single unit and highlight only the words that actually changed rather than the whole block.
